# 文書の案内

どの文書に何を書くかの一覧です。同じことを2か所に書かず、ほかの文書からはリンクで指します。

| 文書 | 読む人 | 書いてあること |
|---|---|---|
| [design.md](design.md) | 判断の理由を知りたい人 | 目的、機能、権限とセキュリティ、認証と課金、費用の見積もり、構成、導入計画、未決事項。**設計の正本**で、仕様を変えるときは同じ変更でここも直す |
| [operations.md](operations.md) | 運用する人 | 仮想料金の確認、回答の直し方、公開への切り替え、共有機への登録、情シスなどへの依頼、困ったとき |
| [usage.md](usage.md) | 利用者(営業・技術サポート) | ボットの使い方。Slack に載せる説明の元にする(試験公開の準備のときに書く) |
| [slack-app.md](slack-app.md) | 情シス、権限を見直す人 | Slack アプリの仕組み、トークン、権限(スコープ)、利用者の制限 |
| [slack-app-setup.md](slack-app-setup.md) | Slack アプリを作る人 | 試験用アプリを作り、インストールして起動するまでの手順 |

文書のほかに、次のファイルも人が読み書きします。

| ファイル | 書いてあること |
|---|---|
| [../README.md](../README.md) | ボットの紹介と、手元で動かすまでの最短の手順 |
| `../.env.example` | 設定の一覧と説明(設定の説明はここだけに書く) |
| `../config/system_prompt.md` | 回答の口調や調べ方の指示 |
| `../knowledge/faq.md` | よくある質問と答え。ボットは最初にここを引く |
| `../config/pricing.toml` | 仮想料金の計算に使う単価 |
| `../slack/manifest.yml` | Slack アプリの設定の実体 |

段階の呼び方は design.md の「導入計画」に合わせ、検証、稟議、試験公開、本公開とします。
