# ZERO QA Bot の使い方

利用者(営業・技術サポートのメンバー)向けの説明です。利用者は GitHub を見られないので、この文書は Slack に載せる説明(アプリのホーム画面やチャンネルのキャンバス)の元にします。

中身は試験公開の準備のときに書きます。書く予定の項目:

- 何に答えるボットか、答えられないこと
- DM での聞き方と、チャンネルでのメンションの仕方
- バージョンの指定と、2つのバージョンの比較
- スクリーンショットやログの添付
- スレッドで会話を続ける、新しい会話を始める
- 👍 / 👎 での評価と、理由の書き方
- 回答を社外に共有するときの注意
- 困ったときの問い合わせ先
